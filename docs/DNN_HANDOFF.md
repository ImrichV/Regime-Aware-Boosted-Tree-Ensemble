# Neural Architecture Handoff

The tree project establishes explicit candidate, feature, regime, and validation contracts. Its main limitation is representational: handcrafted features and tabular trees cannot fully preserve the path into a setup, hierarchical multitimeframe structure, intraday sequencing, human visual labels, or historical analogue geometry.

The related [Regime-Aware Multiscale Neural Architecture](https://github.com/ImrichV/Regime-Aware-Multiscale-Neural-Architecture) extends the same modular discipline with learned sequence encoders, multiscale fusion, analogue retrieval, human-supervised representations, uncertainty, and controlled adaptation.

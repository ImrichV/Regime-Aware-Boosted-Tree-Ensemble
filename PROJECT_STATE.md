# Project State

## Public release

**Status: RESEARCH INFRASTRUCTURE RELEASE**

The public repository contains the generic causal pipeline reconstructed from accepted Modules 00–06, a non-production public candidate example, and a reference regime-aware specialist boosted-tree layer.

## Accepted in the recovered private archive

- repository hardening and unified CLI;
- canonical daily-data engine;
- causal shared-feature engine;
- deterministic candidate framework;
- eleven frozen candidate families;
- separate outcome/label engine;
- selection-safe research table and fixed baseline gate.

## Not accepted as production

- flexible boosted-tree specialist selection;
- regime-gate profitability;
- exit optimization;
- portfolio ranking and allocation;
- live execution;
- unbiased historical performance.

The public boosted-tree code is an architectural reference, not a claim that the final ensemble has passed the private acceptance gates.
